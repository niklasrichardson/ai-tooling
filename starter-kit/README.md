# LLM starter kit

A kit for building software with AI coding tools such as Claude Code, Codex, Claude and ChatGPT. Each file is written for your AI tool to read and set up for you. You do not have to set anything up by hand.

Based on a real set-up from October 2026: one person building three apps with about a dozen long-running AI sessions.

## Files

| File | For | What your AI tool does with it |
|---|---|---|
| `1-response-style.md` | Everyone | Asks you a few questions, then installs instructions that make answers short, structured and honest, with your actions in a numbered list and decisions as lettered options. Works with Claude Code, Codex, Claude and ChatGPT. |
| `2-multi-session-framework.md` | People who run AI sessions on software projects | Interviews you, then sets up roles, instruction files, a decision log, an issue workflow, gated steps for risky work, and handover prompts. Starts small (one session) and grows in 3 phases. |
| `3-example-working-model.html` | Anyone curious | Open it in a browser. It shows the real set-up behind this kit, with the names changed: who does what, folders and repositories, how sessions pick up the rules, and how work gets back into main. |

## How to start

1. Give `1-response-style.md` to your AI tool and say: "Read this file and follow its instructions."
2. Try it for a few days. Change anything you do not like; the instructions are yours.
3. When you run more than one AI session on a project, do the same with `2-multi-session-framework.md`. Start with phase 1.

## Notes

- The AI tool shows you each file before it writes it. Read what it proposes.
- Menu names in Claude and ChatGPT change from time to time. If your tool cannot find a setting, it says so instead of guessing.
- Nothing here needs a paid add-on or a download. The optional message queue in file 2 is described, not supplied: your AI tool can build a small one if you want it.
