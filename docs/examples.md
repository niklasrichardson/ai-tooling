# Examples

My own instructions for each tool, with personal details replaced by `[placeholders]`. All four come from the same rules: a reply template, concision and plain-language rules, critical collaboration, and accurate reporting of work.

| File | Tool | Where it goes |
| --- | --- | --- |
| [`claude-code/CLAUDE.md`](../examples/claude-code/CLAUDE.md) | Claude Code | `~/.claude/CLAUDE.md`. Also has rules for context size, subagent routing and worktree clean-up. |
| [`codex/AGENTS.md`](../examples/codex/AGENTS.md) | Codex | `~/.codex/AGENTS.md` |
| [`claude-ai/account-instructions.md`](../examples/claude-ai/account-instructions.md) | Claude (app and web) | Your profile preferences in Claude's settings, as one block. |
| [`chatgpt/account-instructions.md`](../examples/chatgpt/account-instructions.md) | ChatGPT | Personalisation settings: the custom instructions, occupation and "more about you" fields. |

## How to use them

- Do not copy an example over your own file. Take the sections you want, or let the [starter kit](../starter-kit/README.md) write instructions that fit you.
- Replace each `[placeholder]` with your own details, or delete it.
- `~` is your home folder (on Windows, `C:\Users\<you>`).
- Menu names in Claude and ChatGPT change from time to time. If you cannot find a setting, search the app's help for "custom instructions" or "personalisation".
